## The I-Statement Formula
"I feel [emotion] when [situation] because [reason]. I need [request]."

## Practice I-Statements

| Situation | Passive response | Aggressive response | Assertive response (I-statement) |
|-----------|-----------------|--------------------|---------------------------------|
| Partner doesn't help with chores | Say nothing, feel resentful | "You never do anything!" | "I feel overwhelmed when I handle all the chores. I need us to split tasks." |
| Boss assigns extra work | Accept without question | "That's not my job!" | |
| Friend cancels again | "It's fine" | "You're so unreliable!" | |
| Parent criticises choices | Comply | Yell back | |
