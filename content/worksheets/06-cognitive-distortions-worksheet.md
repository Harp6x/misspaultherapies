## Common Thinking Traps

| Distortion | Definition | Example |
|-----------|-----------|---------|
| All-or-nothing | Seeing things in black/white | "If it's not perfect, it's a failure" |
| Catastrophising | Imagining worst case | "This headache means I'm dying" |
| Mind-reading | Assuming others' thoughts | "They think I'm stupid" |
| Fortune-telling | Predicting negative outcomes | "I'll definitely fail the interview" |
| Personalising | Taking everything personally | "They cancelled because of me" |
| Filtering | Focusing only on negatives | Ignoring 10 compliments, fixating on 1 criticism |
| Should statements | Rigid rules for self/others | "I should be able to handle this" |
| Labelling | Defining self by one event | "I'm a total failure" |
| Magnifying/Minimising | Exaggerating negatives, shrinking positives | "My mistake was huge; my success was nothing" |
| Emotional reasoning | Feelings = facts | "I feel stupid, so I must be stupid" |
