## DEAR MAN Skill — Getting What You Need

| Letter | Skill | Your script |
|--------|-------|-------------|
| **D** | Describe the situation (facts) | "When ____" |
| **E** | Express how you feel | "I feel ____" |
| **A** | Assert what you need | "I need ____" |
| **R** | Reinforce the benefit | "This would help because ____" |
| **M** | Stay Mindful (don't get sidetracked) | Broken record: repeat your point |
| **A** | Appear confident | Eye contact, calm voice |
| **N** | Negotiate if needed | "What would work for you?" |

## GIVE Skill — Keeping the Relationship

| **G**entle | No attacks, threats, or judging |
| **I**nterested | Listen, ask questions |
| **V**alidate | "I understand why you feel that way" |
| **E**asy manner | Light tone, humour if appropriate |
