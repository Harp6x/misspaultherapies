# Progressive Muscle Relaxation (PMR) Worksheet
### Ms Paul Therapies | @mspaultherapies

---

## Instructions
Tense each muscle group for **5 seconds**, then release for **10 seconds**. Notice the contrast.

## PMR Sequence

| # | Muscle Group | Tense (how) | Tension (1-10) | Relaxation (1-10) |
|---|-------------|------------|---------------|-------------------|
| 1 | Right hand/forearm | Make a fist | | |
| 2 | Right upper arm | Bend elbow, flex bicep | | |
| 3 | Left hand/forearm | Make a fist | | |
| 4 | Left upper arm | Bend elbow, flex bicep | | |
| 5 | Forehead | Raise eyebrows high | | |
| 6 | Eyes/cheeks | Squeeze eyes shut | | |
| 7 | Jaw | Clench teeth gently | | |
| 8 | Neck | Press chin to chest | | |
| 9 | Shoulders | Shrug up to ears | | |
| 10 | Chest | Take deep breath, hold | | |
| 11 | Stomach | Tighten abs | | |
| 12 | Lower back | Arch gently | | |
| 13 | Right thigh | Press down on surface | | |
| 14 | Right calf | Point toes up | | |
| 15 | Right foot | Curl toes | | |
| 16 | Left thigh | Press down on surface | | |
| 17 | Left calf | Point toes up | | |
| 18 | Left foot | Curl toes | | |
