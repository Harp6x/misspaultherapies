## Core Emotions → Secondary → Specific

### Happy
- Optimistic → Hopeful, Inspired
- Content → Satisfied, Peaceful
- Proud → Confident, Accomplished
- Playful → Amused, Energetic

### Sad
- Lonely → Isolated, Abandoned
- Vulnerable → Fragile, Helpless
- Guilty → Ashamed, Remorseful
- Depressed → Empty, Hopeless

### Angry
- Frustrated → Annoyed, Irritated
- Bitter → Resentful, Jealous
- Violated → Betrayed, Disrespected
- Aggressive → Hostile, Enraged

### Fearful
- Anxious → Worried, Overwhelmed
- Insecure → Inadequate, Inferior
- Scared → Frightened, Terrified
- Rejected → Excluded, Dismissed

### Disgusted
- Disapproving → Judgmental, Critical
- Disappointed → Let down, Disillusioned
- Repelled → Revolted, Horrified

### Surprised
- Amazed → Astonished, Awestruck
- Confused → Perplexed, Disillusioned
- Startled → Shocked, Dismayed
