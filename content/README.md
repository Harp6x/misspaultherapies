### As Lead Magnets (Email List Growth)

- Send one resource per week/fortnight

- Use checklist items as Instagram stories/polls

- Self-Care Guide → group sessions

## Sanity CMS Integration — Adding Resources to the Live Website

Resources from this content library can be published to the live website via Sanity CMS without touching any code.

### How It Works

1. **Content lives here as markdown** — This `content/` folder is the master source for all resources.
2. **Sanity Studio** — Use the Sanity Studio dashboard to create a new "Resource" document.
3. **Copy content from markdown to Sanity** — Paste the relevant content into the Sanity rich text editor, or use the markdown body field if available.
4. **Set metadata** — Title, category (checklist/guide/questionnaire/workbook/worksheet), slug, description, and publish date.
5. **Publish** — The resource appears on the `/resources` page automatically.

### Recommended Publishing Cadence

- **Week 1-2:** Publish 2-3 checklists (quick wins, high shareability)
- **Week 3-4:** Publish 1-2 guides (SEO value, lead magnets)
- **Monthly:** Add 1 workbook + 2-3 worksheets + 1 questionnaire
- **Goal:** Drip-feed content to keep the website fresh and drive repeat visits

### Sanity Schema (Resource Document)

```javascript
// Suggested Sanity schema for resources
export default {
  name: 'resource',
  title: 'Resource',
  type: 'document',
  fields: [
    { name: 'title', type: 'string', title: 'Title' },
    { name: 'slug', type: 'slug', title: 'Slug', options: { source: 'title' } },
    { name: 'category', type: 'string', title: 'Category',
      options: { list: ['checklist', 'guide', 'questionnaire', 'workbook', 'worksheet'] } },
    { name: 'description', type: 'text', title: 'Description' },
    { name: 'body', type: 'array', title: 'Body', of: [{ type: 'block' }] },
    { name: 'downloadUrl', type: 'url', title: 'PDF Download URL (optional)' },
    { name: 'published', type: 'boolean', title: 'Published', initialValue: false },
    { name: 'publishedAt', type: 'datetime', title: 'Published At' },
    { name: 'topics', type: 'array', title: 'Topics', of: [{ type: 'string' }] },
  ]
}
```

### No Code Changes Needed

The website's `/resources` page already fetches from Sanity. Simply create documents in Sanity Studio and set `published: true` to make them live.
