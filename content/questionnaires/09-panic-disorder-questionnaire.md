## Part 1: Panic Attack Frequency

In the past month:
- How many panic attacks have you experienced? ____
- Were any unexpected (no obvious trigger)? ☐ Yes ☐ No
- How long do they typically last? ____ minutes

## Part 2: During Your Most Recent Panic Attack

Check all symptoms experienced:

- ☐ Racing or pounding heart
- ☐ Sweating
- ☐ Trembling or shaking
- ☐ Shortness of breath or feeling smothered
- ☐ Chest pain or tightness
- ☐ Nausea or stomach distress
- ☐ Dizziness or lightheadedness
- ☐ Chills or hot flashes
- ☐ Numbness or tingling
- ☐ Feeling detached from yourself (depersonalisation)
- ☐ Fear of losing control or "going crazy"
- ☐ Fear of dying

**Symptoms checked: ____ / 12**

## Part 3: Impact Assessment

**Scale:** 0 = Not at all | 1 = A little | 2 = Moderately | 3 = A lot | 4 = Extremely

| # | Question | 0 | 1 | 2 | 3 | 4 |
|---|----------|---|---|---|---|---|
| 1 | How much do you worry about having another panic attack? | | | | | |
| 2 | How much do you avoid places/situations because of panic? | | | | | |
| 3 | How much has panic affected your work/studies? | | | | | |
| 4 | How much has panic affected your relationships? | | | | | |
| 5 | How much has panic affected your daily activities? | | | | | |

**Impact Score: ____ / 20**

## Interpretation

- **4+ symptoms during attacks + Impact score 8+:** Likely panic disorder — professional assessment recommended
- **Unexpected attacks + persistent worry:** Classic panic disorder pattern
- **Avoidance of situations:** Agoraphobia may be developing
