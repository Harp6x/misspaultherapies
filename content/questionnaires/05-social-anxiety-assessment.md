## What Is Social Anxiety?

Social anxiety is more than shyness. It's an intense fear of being judged, embarrassed, or humiliated in social situations. It can affect work, relationships, and daily activities.

**Social anxiety is the 3rd most common mental health condition** — you are not alone.

## Part 2: The Social Anxiety Cycle

Understanding the cycle helps break it:

```
Anticipation ("This will go badly")
    ↓
Physical Symptoms (blushing, sweating, trembling, racing heart)
    ↓
Safety Behaviours (avoiding eye contact, staying quiet, rehearsing)
    ↓
Post-Event Processing ("I was so awkward, everyone noticed")
    ↓
Avoidance (skipping next event)
    ↓
Anxiety Strengthens → Cycle Repeats
```

### Strategy 2: Dropping Safety Behaviours

Safety behaviours feel protective but maintain anxiety. Gradually reduce them:

| Safety Behaviour | What I'll Try Instead |
|-----------------|----------------------|
| Avoiding eye contact | Brief eye contact, then look away naturally |
| Staying silent | Asking one question in a conversation |
| Over-preparing what to say | Speaking more spontaneously, accepting imperfection |
| Hiding (standing in corners, phone as shield) | Standing in the middle of the room for 5 minutes |
| Apologising excessively | Reducing apologies to only when genuinely needed |

### Strategy 3: Gradual Exposure Ladder

Build a ladder from easiest to hardest. Start at the bottom:

| Step | Social Challenge | Anxiety Before (0–10) | Anxiety After (0–10) | Done? |
|------|-----------------|----------------------|---------------------|-------|
| 10 | (Hardest: _______________) | | | |
| 9 | | | | |
| 8 | | | | |
| 7 | | | | |
| 6 | | | | |
| 5 | | | | |
| 4 | | | | |
| 3 | | | | |
| 2 | | | | |
| 1 | (Easiest: _______________) | | | |

**Rules for the ladder:**
- Start at step 1 only when you're ready
- Repeat each step until anxiety drops to 3 or below
- Don't skip steps
- Celebrate every step completed — this takes real courage
- If a step feels too hard, add a smaller step between

### Strategy 4: Self-Compassion After Social Events

Replace post-event rumination with:
1. "I showed up. That took courage."
2. "People are less focused on me than I think."
3. "Awkward moments are human, not catastrophic."
4. "I'm learning. Every exposure makes me stronger."

## When to Seek Help

- [ ] You avoid situations that are important for your career or relationships
- [ ] Anxiety is present in most social situations, not just a few
- [ ] You use substances to get through social events
- [ ] You've felt this way for 6 months or more
- [ ] Self-help strategies aren't enough

**CBT is the gold standard treatment for social anxiety. It works for 60–80% of people.**
