## Part 1: Has there ever been a period when you were NOT your usual self and...

| # | Experience | Yes | No |
|---|-----------|-----|----|
| 1 | You felt so good or hyper that others thought you were not your normal self | | |
| 2 | You were so irritable that you shouted at people or started fights | | |
| 3 | You felt much more self-confident than usual | | |
| 4 | You got much less sleep than usual and didn't miss it | | |
| 5 | You were much more talkative than usual | | |
| 6 | Thoughts raced through your head | | |
| 7 | You were so easily distracted that you couldn't concentrate | | |
| 8 | You had much more energy than usual | | |
| 9 | You were much more active or did many more things than usual | | |
| 10 | You were much more social or outgoing than usual | | |
| 11 | You were much more interested in sex than usual | | |
| 12 | You did things that were unusual for you or others thought were excessive or risky | | |
| 13 | Spending money got you or your family in trouble | | |

## Part 2: If you checked YES to 7+:

- Did several of these happen during the same period? ☐ Yes ☐ No
- How much of a problem did they cause? ☐ No problem ☐ Minor ☐ Moderate ☐ Serious

## Screening Result

**7+ Yes answers + same time period + moderate/serious problems = positive screen for bipolar disorder**

This does NOT mean you have bipolar disorder. It means a comprehensive psychiatric evaluation is recommended.
