## How to Use This Content Bank

### For Email Marketing (Kit)
1. Set up the **Welcome Sequence** first (7 emails, auto-triggered on signup)
2. Add topic sequences for engaged subscribers (anxiety, self-care, couples)
3. Load mini-courses as separate opt-in sequences
4. Schedule monthly newsletters (one per month, content is ready)

### For Instagram (@mspaultherapies)
1. Follow the **52-week calendar** — it tells you what to post each week
2. Use **carousel scripts** — each slide is written; just design in Canva
3. Mix in **quote posts** (2/week) between carousels and reels
4. Use **challenges** as interactive campaigns (stories + hashtag)

### For Clients
1. Send **onboarding pack** before first session
2. Give **between-sessions toolkit** after first session
3. Give **graduation pack** when therapy ends

### For Seasonal Campaigns
1. Check the **year-long calendar** in MASTER-RCA.md
2. Deploy seasonal kits 1–2 weeks before the relevant period
3. Pair with matching newsletter + social media posts
