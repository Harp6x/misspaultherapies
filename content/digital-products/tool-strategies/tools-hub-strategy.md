# Tools Hub — Product Strategy

## Product Concept
A central index page at `/tools` that showcases all interactive mental health tools. Acts as the primary gateway for engagement, SEO, and lead generation. Positioned as "Tools for When You Need a Moment" — clinically informed, free, no-login, privacy-first.

## Target Emotional Pain Point
"I need something right now but I don't know what." — People in emotional distress looking for immediate, accessible support that doesn't require commitment. Also targets curious browsers who want to explore their mental health.

## User Journey
1. **Discovery** → Direct nav from header, social links, Google ("free mental health tools online")
2. **Browse** → Grid of tools with icons, descriptions, pain point quotes, live/coming soon tags
3. **Select** → Click through to specific tool
4. **Loop** → Complete one tool → return to hub → try another
5. **Convert** → Each tool has its own email capture + therapy CTA

## UI/UX Structure
- Header nav link: "Tools" (between Resources and Gallery)
- Hero: uppercase label + serif heading + descriptive subtext
- 3-column responsive grid of tool cards
- Each card: icon, title, description, pain point quote (italic), tag (Live/Coming Soon), CTA
- "Why These Tools?" explainer section
- Bottom CTA: "Need More Than Self-Help?" → discovery call

## Current Tools (Live)
1. **Emotional Check-In** — mood, body, thoughts, needs → personalized reflection
2. **Burnout Assessment** — 12 questions, 3 subscales, tiered result

## Planned Tools (Coming Soon)
3. **Guided Reflection** — adaptive therapeutic prompts by theme
4. **AI Journaling** — free prompts + optional AI-powered insights
5. **Self-Awareness Journey** — 7-day guided exploration
6. **Relationship Reflection** — solo or partner mode

## SEO Opportunities
- **Primary:** "free mental health tools", "online therapy tools free", "mental health self-help tools"
- **Long-tail:** "free emotional check-in tool", "burnout quiz online free", "mental health assessment no login"
- **Hub page:** Strong internal link equity — links to all tool subpages
- **Schema:** ItemList, WebApplication

## Email Funnel Ideas (Hub-Level)
- **Tag:** tools-user
- **Trigger:** Any tool completion → add to tools-user segment
- **Nurture:** "3 tools to try this week based on what you told us" (personalised by tool used)
- **Re-engagement:** Monthly "new tool launched" announcements

## Monetization Potential
- Hub itself is free (top-of-funnel)
- Individual tools drive email capture → paid product upsells
- Aggregate engagement data informs product development
- Corporate licensing: entire tools suite for workplace wellness portals

## Engagement Hooks
- **Variety:** Multiple tools encourage browsing and return visits
- **Progress:** "Coming Soon" tags create anticipation
- **Pain point matching:** Each card shows the exact problem it solves
- **Low commitment:** "Free · No Login · Clinically Informed" removes barriers
