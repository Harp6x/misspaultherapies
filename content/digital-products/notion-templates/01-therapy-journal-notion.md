## Template Structure

### Database 1: Session Log
| Property | Type | Description |
|----------|------|-------------|
| Session # | Number | Auto-increment |
| Date | Date | Session date |
| Therapist | Text | Name |
| Topics Discussed | Multi-select | Tags: anxiety, relationships, family, trauma, work, self-esteem, etc. |
| Mood Before (1-10) | Number | Pre-session mood |
| Mood After (1-10) | Number | Post-session mood |
| Key Insight | Text | One sentence takeaway |
| Homework | Text | What to practice before next session |
| Homework Done? | Checkbox | Accountability |
| Notes | Long text | Detailed session notes |

### Database 2: Weekly Check-In
| Property | Type | Description |
|----------|------|-------------|
| Week of | Date | Monday of that week |
| Overall Mood (1-10) | Number | Average for the week |
| Anxiety Level (1-10) | Number | |
| Sleep Quality (1-10) | Number | |
| Highlight | Text | Best moment |
| Challenge | Text | Hardest moment |
| Coping Tools Used | Multi-select | Breathing, journaling, exercise, grounding, etc. |
| Gratitude | Text | 3 things |
| Self-Care Rating | Select | Great / Good / Okay / Needs work |

### Database 3: Thought Records (CBT)
| Property | Type | Description |
|----------|------|-------------|
| Date | Date | |
| Situation | Text | What happened |
| Automatic Thought | Text | What went through my mind |
| Emotion | Multi-select | Anxious, sad, angry, ashamed, etc. |
| Intensity (0-100) | Number | Before challenge |
| Evidence For | Text | |
| Evidence Against | Text | |
| Balanced Thought | Text | |
| New Intensity (0-100) | Number | After challenge |

### Database 4: Medication & Symptom Tracker
| Property | Type | Description |
|----------|------|-------------|
| Date | Date | |
| Medication Taken | Checkbox | |
| Side Effects | Text | |
| Mood (1-10) | Number | |

## How to Share as Notion Template

1. Create the template in your Notion workspace
2. Click "Share" → "Share to web" → Enable "Allow duplicate as template"
3. Copy the link
4. List on: Notion Template Gallery, Gumroad (₹0), Topmate, Instagram link-in-bio
